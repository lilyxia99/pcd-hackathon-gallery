CHEAT CODE — save a GIF from your sketch:
Paste the code below at the very bottom of your sketch (outside draw()), click the sketch canvas, then press S for a 5-second GIF or P for a still image.

// Save a 5-second gif when the user presses the 's' key.
function keyPressed() {
  if (key === 's') {
    saveGif('mySketchGif', 5);
  }
  if (key === 'p') {
    save('mySketchImage.png');
  }
}

Uploaded files go to the gallery image host and are attached to your entry automatically. If you pick more than one, the GIF wins.
